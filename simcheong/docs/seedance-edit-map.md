# 심청전 — Seedance 클립 편집 지도

> `npm run seedance:map`이 `src/data/narration.ts`에서 생성한다.
> 직접 고치지 말고 원본을 고친 뒤 다시 돌린다.

## 요약

| 항목 | 값 |
|---|---|
| 생성할 클립 | **25개** × 20초 = 500초 |
| 최종 러닝타임 | **7:26.0** (446초) |
| 버리는 분량 | 54.0초 (클립당 평균 2.2초) |

클립마다 **꼬리를 잘라** 쓴다. 프롬프트의 마지막 비트(16–20초)는 정지 상태를
붙잡고 있는 구간이라 여기서 가져오면 본동작이 상하지 않는다.

컷이 사설 중간에 떨어지는 것은 문제가 아니다 — 내레이션은 별도 트랙으로
위에 얹힌다. 아래 표에서 **⚠ 표시된 줄만** 주의하면 된다. 그 줄은 클립
경계를 넘어가므로, 앞뒤 클립의 그림이 서로 이어져 보여야 한다.

## 조립 순서

1. 프롬프트 25개로 클립을 생성한다 (`docs/seedance-prompts.md`)
2. 클립마다 위 표의 **사용 길이만큼 앞에서 잘라** 순서대로 잇는다
3. 사설 67줄을 fish.audio에서 받는다 (`docs/audio-script.md`)
4. `npm run audio:manifest`
5. 음성을 **실제 녹음 길이로 재배치**한다 — 아래 주의 참조

> **타이밍의 기준은 `narration.ts`의 `at`/`until`이 아니라 실제 녹음 길이다.**
> 그 값들은 화면 자막용으로 정한 것이고, 창(23줄)은 감정을 실으면 대개
> 길어진다. 녹음이 길어지면 그 줄이 걸친 클립의 사용 길이를 늘려 맞춘다
> — 버리는 분량이 클립마다 남아 있으므로 여유가 있다.
