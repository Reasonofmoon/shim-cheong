# 심청전 — 절차적 Three.js 렌더

한국 고전 「심청전」을 **에셋 없이 코드만으로** 지어 올린 8막 애니메이션.
`.glb` 모델도, 텍스처 이미지도, 오디오 파일도 없다. 화면에 보이는 모든 폴리곤이
런타임에 계산된다.

```bash
npm install
npm run dev      # http://localhost:5178
npm run build    # tsc --noEmit && vite build
```

## 어떻게 만들어졌나

### 지붕이 가장 어려웠다

한국 지붕이 중국·일본과 다르게 보이는 건 세 가지 곡선 때문이다.
[`roof.ts`](src/builders/roof.ts)는 이걸 곡면 함수 하나의 항으로 표현한다.

- **앙곡(昻曲)** — 처마 끝이 위로 들림 → `angok * |edge|⁴ * v^2.6`
- **안허리곡** — 평면상 처마가 바깥으로 휨 → `1 + anheorigok * |edge|³ * v²`
- **오목한 지붕면** — 용마루 쪽은 급하고 처마 쪽은 완만 → `1 - (1-v)²`

기와 골은 별도 메시가 아니다. 곡면 자체를 `cos²`로 변조해서 굽는다 —
추가 드로우콜 0개, flat shading이 알아서 각을 세운다. 초가지붕은 같은 슬롯에
노이즈를 넣은 것뿐이다. 그래서 초가집·절·궁궐·상여·석탑이 전부 같은 함수다.

### 파동 함수는 두 번 쓰였다

[`water.ts`](src/builders/water.ts)의 Gerstner 파동 4개는 GLSL과 TypeScript에
**같은 식으로 두 번** 존재한다. 이 중복이 사는 이유는 하나다 — 배와 연꽃이
"대충 사인파 위에서 흔들리는" 게 아니라 **실제로 그려지고 있는 그 수면 위에
떠 있다**. 갑판이 기울면 그 위 인물도 같이 기울고, 뒤의 수평선도 같은 각도로
기운다.

### 인물은 리그 하나다

심청, 심봉사, 스님, 뱃사람, 궁녀, 맹인 24인 — 전부
[`figure.ts`](src/builders/figure.ts)의 같은 리그에 옷 색만 다르다.
한복이 한복으로 읽히는 건 실루엣 두 개 덕분이다.

- **여성**: 가슴 아래서 끝나는 아주 짧은 저고리 + 가슴부터 발목까지 종처럼
  떨어지는 치마. 허리가 안 보인다. 저고리를 충분히 짧게 만드는 것 하나가
  "그냥 로브"를 "한복"으로 뒤집는다.
- **남성**: 엉덩이까지 오는 저고리 + 허벅지에서 부풀고 발목에서 대님으로 묶는
  바지, 그리고 갓.

포즈는 순수 함수다. 막은 시간 `t`만 받아 자세를 계산하므로, 스크러버로 7분짜리
영상의 아무 프레임이나 찍어도 구도가 정확히 재현된다. 이 성질이 없었으면
아래의 감사 루프가 성립하지 않았다.

## 자기 결과물을 보는 문제

이 프로젝트의 진짜 난이도는 지오메트리가 아니라 **만든 걸 확인하는 것**이었다.
코드 리뷰로는 하나도 안 잡히고 렌더를 봐야만 보이는 버그가 계속 나왔다.

그래서 `window.simcheong`에 조회 훅을 붙였다:

```js
simcheong.goTo(4, 30)      // 5막 30초로 점프하고 일시정지
simcheong.inspect(40)      // 40 units 넘는 오브젝트의 월드 바운딩박스
simcheong.facing('father') // 이 인물이 카메라를 보고 있나? (dot -1~1)
simcheong.toggle('ridgelines')
simcheong.camera()
```

실제로 잡힌 것들:

- **정점 컬러 없는 메시가 새까맣게** — `vertexColors: true`인데 지오메트리에
  `color` 속성이 없으면 WebGL이 `(0,0,0)`을 넣는다. 경고도 없다. 문살·창틀·감
  열매가 전부 검정이었다. → `meshOf` 관문에서 불변식 강제.
- **Ocean이 자체 포그 유니폼을 들고 있었다** — `ShaderMaterial`은 three의 자동
  포그 주입을 못 받는다. 한 막이 동기화를 빠뜨려 밤 폭풍우 수평선에 베이지색
  띠가 그어졌다. → `update(t, stage)`로 stage를 필수 인자로 만들어 구조적으로 해결.
- **metalness 0.7 + 환경맵 없음 = 검은 구멍** — 궁궐 연못이 화면 구석의 void였다.
  → `stillWater()` 헬퍼로 통일.
- **좌표 슬롯 실수** — 7막 연못 샷에서 `POND_Z`를 z가 아닌 y 자리에 넣어 카메라가
  지하 300 units에 있었다. 그 막 전체가 안개뿐이었다.
- **연꽃이 안 벌어졌다** — 꽃잎 피벗을 접선이 아니라 반경 방향 축으로 돌리고
  있었다. "개화"가 옆으로 비트는 동작이 되어 봉오리 그대로였다.
- **원경 능선이 화면을 덮었다** — 지형 패치(340 units) 가장자리 너머는 허공이라
  광각에서 능선 밑동이 드러났다. → Stage에 반경 6000 월드 바닥 추가.
- **방향은 추측하면 틀린다** — 인물이 등을 돌렸다고 40분 확신했는데 `facing()`으로
  재보니 `dot 0.70`, 처음부터 정면이었다. 진짜 문제는 이목구비가 너무 작아
  안 읽히는 것이었다.

자세한 기록은 [`../tasks/lessons.md`](../tasks/lessons.md).

## 구조

```
src/
  core/       stage, director, cameraRig, shot, timeline, palette, rng, subtitles, ui
  builders/   roof, hanok, temple, figure, nature, water, ship, dragon, undersea, lotus, props
  scenes/     act01 ~ act08
  data/       narration.ts  (판소리 사설체 자막)
```

- **머티리얼은 캐시하고 지오메트리만 막마다 해제한다.** 머티리얼은 100개 남짓이라
  누수가 없고, 살려두면 스크러버로 되돌아온 막이 셰이더를 재컴파일하지 않는다.
  지오메트리는 막마다 수만 정점이라 `disposeTree`로 정리한다.
- **오방색(청·적·황·백·흑)과 단청 안료**가 [`palette.ts`](src/core/palette.ts)에
  모여 있다. 텍스처가 없으니 팔레트가 미술감독이 사는 유일한 장소다.
- 텍스처 없는 표면이 플라스틱처럼 보이는 걸 막는 건 `applyVertexTint` —
  정점별로 밝기를 ±5% 흔들면 기와 300장이 전부 같은 색이어도 구운 흙처럼 읽힌다.
